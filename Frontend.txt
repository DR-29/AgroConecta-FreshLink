================================================================================
           RESUMEN Y EXPLICACIÓN DE LA ESTRUCTURA DEL FRONTEND
================================================================================

--------------------------------------------------------------------------------
1. CARPETAS EN LA RAÍZ DE frontend/
--------------------------------------------------------------------------------
* dist/
  Carpeta donde Vite genera los archivos compilados de producción (HTML, CSS y JS 
  optimizados) al ejecutar 'npm run build'.

* node_modules/
  Carpeta con todas las librerías y dependencias externas instaladas (React, React Router, Vite, etc.).


--------------------------------------------------------------------------------
2. CÓDIGO FUENTE EN src/ (Arquitectura React)
--------------------------------------------------------------------------------

[Carpetas de Arquitectura]
* api/
  Capa de comunicación HTTP ('client.js' y 'endpoints.js') con las funciones que 
  llaman a la API REST del backend enviando el Token JWT.

* components/
  Componentes visuales reutilizables en toda la app ('Navbar.jsx', 'Sidebar.jsx', 'Icons.jsx').

* contexts/
  Estado global de la aplicación ('AuthContext.jsx' para gestionar login, logout, 
  sesión activa y guardar el token en localStorage).

* hooks/
  Custom hooks de React para encapsular lógica reutilizable entre vistas.

* layouts/
  Plantillas estructurales base que envuelven las páginas agregando la barra superior 
  y el menú lateral según el rol.

[Carpeta pages/ - Vistas de la aplicación]
* pages/admin/
  Módulo del Administrador (gestión de usuarios, catálogo global, soporte de reclamaciones 
  e indicadores de gestión).

* pages/auth/
  Módulo de autenticación (pantalla de registro de nuevas cuentas 'RegisterPage.jsx').

* pages/productor/
  Módulo del Productor agrícola (panel, mis fincas, inventario de productos, pedidos 
  recibidos y directorio de transportistas).

* pages/tienda/
  Módulo de la Tienda compradora (panel, catálogo de búsqueda y compra, seguimiento GPS 
  de pedidos y reclamaciones enviadas).

* pages/transportista/
  Módulo Logístico del Transportista (panel, solicitudes de flete, servicios activos 
  con GPS, gestión de vehículos y estado de disponibilidad).

* pages/.gitkeep
  Archivo técnico para preservar la estructura de carpetas en Git.

* pages/LoginPage.jsx
  Pantalla de inicio de sesión con correo y contraseña.

* pages/PerfilPage.jsx
  Vista donde cualquier usuario consulta y edita sus datos personales o actualiza su contraseña.

* pages/RoleDashboard.jsx
  Enrutador inteligente que redirige automáticamente al usuario a su panel correspondiente 
  según su rol ('/admin', '/productor', '/tienda', '/transportista').

* pages/UnauthorizedPage.jsx
  Pantalla de acceso denegado (Error 403) cuando un usuario intenta ingresar a una 
  sección no permitida para su rol.

[Enrutamiento y Archivos Base de src/]
* routes/
  Componentes de seguridad de rutas ('ProtectedRoute.jsx' que valida token JWT y rol permitido).

* App.jsx
  Componente central que define todo el mapa de rutas navegables de la plataforma.

* main.jsx
  Punto de entrada de JavaScript que arranca React y renderiza la aplicación en el navegador.

* styles.css
  Hoja de estilos globales Vanilla CSS (tokens de color, botones, tablas, cartas, 
  modales y tipografía DM Sans).


--------------------------------------------------------------------------------
3. ARCHIVOS CONFIGURACIÓN EN LA RAÍZ DE frontend/
--------------------------------------------------------------------------------
* .env.example
  Archivo con variables de entorno de ejemplo (ej: URL del backend http://localhost:8080/api).

* index.html
  Estructura HTML principal donde se cargan las fuentes de Google Fonts y se monta React.

* package.json
  Configuración del proyecto Node.js, dependencias y comandos ('npm run dev', 'npm run build').

* pnpm-lock.yaml
  Archivo de control de versiones exactas de las librerías instaladas.

* vite.config.js
  Archivo de configuración del empaquetador Vite (servidor local de desarrollo, puerto 5173).
